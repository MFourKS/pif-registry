# Пул вопросов

Что в задании допускает разные прочтения, какое решение принято сейчас и что изменится, если ответ другой.

### Состав реестра

1. **Что значит «розничные» при наличии фондов для квалифицированных инвесторов?**
   В заголовке «розничные», а в задании «все действующие открытые, интервальные и биржевые».
   По реестру ЦБ 166 из 177 интервальных фондов предназначены для квалифицированных инвесторов.
   Сейчас: в реестр вошли все, на сайте есть метка и фильтр. Если нужны только розничные, отсекается одной строкой.

2. **Что считать действующим фондом?**
   В реестре есть статусы «Сформирован», «Формируется», «В стадии прекращения». Сейчас: «Исключён из реестра»
   убран, остальные показаны со статусом. Формирующиеся фонды (16) идут без ряда с понятной причиной.

3. **Что считать категорией?**
   В реестре ЦБ у этих фондов всего три категории, и 396 из 562 попадают в одну. Для выбора фонда это бесполезно.
   Сейчас: есть оба фильтра, категория ЦБ и наш класс активов (акции, облигации и т. п.). Класс активов считается
   эвристикой по названию и подписан как расчётный. Нужна ли официальная классификация?

### Источники и ограничения

4. **Как относиться к robots.txt?** Самый важный вопрос. В задании сказано про частоту запросов, честный User-Agent и
   закрытые разделы, про robots.txt не сказано.
   - Шаблонный `Disallow: /upload/` из Битрикса есть на сайтах многих УК, а обязательные к раскрытию КИД лежат как раз там.
   - Сейчас: страницы обходятся строго по robots.txt. Файлы раскрытия по прямой ссылке с открытой страницы скачиваются
     даже под таким правилом и помечаются в манифесте как `robots_disallowed_public_document`.
   - `PIF_STRICT_ROBOTS=1` отключает это исключение. Покрытие заметно упадёт.
   - Сайты с `Disallow: /` для всех (Райффайзен, Арсагера, МКБ) считаются закрытыми: туда сбор не ходит, статус показан.
     Это 21 фонд. Если такие сайты можно обходить, покрытие вырастет сразу на эти фонды.
   - Служебные адреса тоже закрыты. У ДОХОДЪ есть дневной ряд по 24 фондам, но он отдаётся через `connectorweb.php`, а
     `Disallow: /*.php` это запрещает. У Озона закрыт `/api/`, у ТЕТИС раздел фондов. Поэтому у ДОХОДЪ только последний КИД.
     Если разрешите, дневной ряд ДОХОДЪ подключается за час.

5. **Считается ли Мосбиржа первичным источником?** ISIN и тикеры взяты из ISS как официальный источник организатора
   торгов. У iss.moex.com в robots.txt закрыто всё, хотя ISS создан для программного доступа. Для него и только для него
   проверка robots отключена.

6. **Можно ли обращаться в УК напрямую?** БКС закрыт антибот-защитой (17 фондов). Обходить её нельзя, поэтому статус
   «блокирует автоматический доступ». Подойдёт ли такой статус или нужны другие законные каналы, например раскрытие на
   сайте агента?

### Методика

7. **Как считать фонды с выплатой дохода?** Выплата снижает и пай, и СЧА, поэтому формула из задания не считает её
   оттоком. Это, по-моему, верно: пайщик не выходил из фонда. Но доходность по ряду пая у таких фондов ниже официальной,
   потому что КИД учитывает выплаты. Сейчас такие расхождения попадают в отчёт с причиной. Нужно ли собирать размер
   выплат и считать полную доходность?

8. **Достаточно ли месячных точек из КИД?** В задании «с той частотой, с какой публикует УК». Часть УК показывает
   дневные значения только через свой JS-интерфейс. Сейчас для них ряд месячный, частота видна на карточке фонда.
   Притоков и сверки это не ухудшает, но график реже. Считается ли это выполнением требования?

9. **Как быть с фондами, закрытыми за период?** Присоединённые фонды исключены из реестра, и притоки по ним не считаются,
   хотя деньги перешли в фонд-преемник. В итоге у преемника виден ложный приток. Сейчас это описано как ограничение. Нужно
   ли строить цепочки присоединений? Реестр ЦБ для этого даёт основание и дату исключения.

10. **Что делать с месяцем, в котором нет полного набора фондов?** Итог рынка за месяц складывается только из фондов
    с двумя точками, поэтому состав меняется. Оставлено так, с оговоркой на странице. Нужен ли сопоставимый состав?

### Публикация и обновление

11. **Что блокирует публикацию?** «Нет ошибок сбора и разбора» и «один сломанный сайт не роняет весь сбор» можно
    понять по-разному. Сейчас публикацию блокируют ошибки разбора, разрывы в сверке итогов и массовый сбой: если не обновилось
    больше 10 % рядов. Один недоступный сайт превращается в статус фонда, иначе он останавливал бы обновление всех данных.

12. **Откуда запускать сбор по расписанию?** Проверено запуском: с адресов GitHub сайты ВИМ, ВИМ Сбережения, ААА и АК БАРС
    отвечают 403. Сейчас расписание работает на GitHub и пропускает эти УК, они обновляются запуском из России. Для полного
    обновления нужен раннер в России, он задаётся переменной `UPDATE_RUNNER`. Есть ли у вас такой раннер или сервер?

13. **Адрес карточки в «Сравнить УК».** Ссылки ведут на `/sravnenie/uk/<внутренний id>`, id берётся из `/sravnenie-data`
    по ИНН. Стабилен ли этот id, или лучше договориться о ссылке по ИНН?

14. **Транзитивные лицензии.** В задании разрешены MIT, BSD, Apache 2.0 и ISC. С `httpx` приходит `certifi` (MPL-2.0), а со
    многими пакетами `typing_extensions` (PSF-2.0). Они работают только при сборе и в сайт не попадают. Этого достаточно?
