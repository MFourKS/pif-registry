# Записка про ИИ

## Инструменты

Проект написан с Claude Code (модель Claude Opus 5.5): разведка источников, код, тесты, документация.
Модель работала на локальной машине через терминал и встроенный браузер.

## Где ИИ ошибся и как это заметили

1. **Чужой ряд у фонда.** Страницы фондов сопоставлялись с реестром по заголовку, и у фонда «ТКБ Инвестмент Партнерс –
   Золото» оказался дневной ряд другого фонда: пай 58,82 вместо 4 965,94. Тесты это не поймали. Заметила самопроверка:
   доходность за 3 месяца разошлась с официальной на 8 п. п. После этого появилась сверка дневного ряда с КИД: КИД сам
   называет фонд, поэтому при расхождении ряд отбрасывается.

2. **Все КИД одной УК легли в один фонд.** В шапке КИД у Арикапитала перечислены все фонды компании, а разборщик брал
   первое название. Заметили по странной цифре в логе: 120 документов и один фонд с данными из семи. Теперь название
   берётся из заголовка и раздела 1, а два разных КИД на одну дату у одного фонда считаются конфликтом.

3. **Числа не из той строки.** Первая версия разбора КИД брала первое число после подписи и принимала «30.09» за стоимость
   пая, а сноску «3» за СЧА. Позже нашлись проценты вместо пая и переставленные местами суммы. Из-за одной такой точки
   приток рынка за год показал −149 589 трлн рублей, это было видно на странице «Рынок». Теперь суммы сопоставляются с
   подписями по позиции, а неправдоподобный приток не считается и попадает в журнал.

4. **Разбор PDF остановил весь сбор.** Модель написала синхронный разбор внутри `asyncio`, и цикл событий блокировался:
   сеть простаивала, а прогон не двигался. Заметили по времени процессора и пустому логу. Разбор вынесен в пул процессов
   с кэшем по SHA-256.

5. **Обновление в CI считалось рабочим без проверки.** Модель написала workflow и считала, что демо после него обновится.
   Запуск на GitHub показал две ошибки: коммит от встроенного токена не запускает выкладку, а сайты ВИМ, ААА и АК БАРС
   отвечают адресам GitHub ошибкой 403, при этом ворота пропустили такой сбой. Теперь выкладка вызывается явно, массовый
   сбой запрещает публикацию, а закрытые для GitHub УК в расписании пропускаются.

## Что проверяли руками

Заполнить перед сдачей: что проверено человеком лично. Таблица ручной сверки лежит в `data/manual_check.csv`.
Сверка значений, которую сделала модель, в ней отмечена отдельно и человеческой проверкой не считается.

Что модель проверила сама:

- значения в тестах КИД сняты с настоящих документов;
- 15 значений из таблицы ручной сверки сверены с заново скачанными файлами другой библиотекой;
- повторный запуск проверен на отсутствие скачиваний и на совпадение сборки по хешам;
- сайт просмотрен на ширине 360 px и на десктопе, демо проверено на GitHub Pages.
